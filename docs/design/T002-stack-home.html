Rules for T004

Settled in grilling (2026-09-14)

  • Delegate target = card selects it. One target, no picker. Default on load: the first mate with no project focus, or the sole project.
  • Quota chip = worst of the two windows (5-hour vs 7-day), as a percent; calm (<60) → warn (60–85) → hot (>85). Tap reveals both.
  • Card states: running (sage) · idle (grey) · blocked (red, i.e. a needs-you item exists). Each shows current activity and progress. The chip names the answering agent (first mate or a project's second mate), per ADR 0030/0033.
  • Touch: every tappable control ≥ 44px tall.
  • Approved by the captain 2026-10-06. Re-pointed after the Maestro retirement (ADR 0033): the delegate target is the first mate or a project's second mate, not a Maestro.
  • Out of scope: Work view internals (T003), project create/manage (T011).
