One row, two tap targets

Header opens the tab · actions answer in place

The row

Every row carries the same four things, whatever the kind: entity (mono, the address), kind badge (colour-coded, with a sub-label for gates), summary (what it wants, in the maestro's own words), and its inline action. The header is one tap target — it opens that entity's Work-view tab. The action row is the other — it resolves the row where it stands, and the row animates out.

A gate row is three shapes behind one badge, because the human is deciding three different things: plan shows the plan collapsed with Approve / Reject, ask shows the harness's own options as buttons, permission shows plain Allow / Deny.

Where each action already goes

errored
/api/command → /reset <entity>
decision
/api/decision/<entity>/reply · entity-keyed, not row-id'd
gate
/api/gate/<id>/{approve,deny}
mode
/api/mode-request/<id>/{approve,deny}
vault
/api/vault-action/<id>/{approve,deny}

No new mechanics. T004 adds one needs_you rollup over the stores that already back these, and deletes the two bells and three bubble renderers.

4

Two things settled at review — for T004

Approved 2026-09-09 · these are the rules T004 implements

Lane ordering: by kind, fixed

Rows sort by kind in a fixed order — errored → decision → gate → mode → vault — as shown in the hero above. The same kind always sits in the same place, so your thumb learns where to reach. Rejected: oldest-waiting-first (reshuffles under you) and by-kind-then-age (more logic in T004 for little gain).

Compact strip: this tab's items only

In the Work view the strip shows only rows for that tab's own maestro, with full inline actions — answerable in place, as shown in section 3. Rejected: every item in every tab (noisier) and a collapse-on-tap count bar (costs a tap on every interrupt).

This is a mockup: the buttons do nothing and the data is invented. It is the approved design spec for T001 — the lane component, its five kinds (with three gate sub-shapes), both sizes, and the calm empty state — that T004 implements into src/hive/web.
