  its own teams/sprints). Keep it scoped or it overruns the close-out.
- **009 is cross-cutting.** Fixing how the service resolves `claude`
  touches the systemd unit + the deploy runbook (`docs/DEPLOYMENT.md`);

  Fake/mocked PTY adapter (hermetic), not drive a real `claude`.
- **011 floor set too high** breaks the build; measure current coverage
  and set the ratchet just under it.
