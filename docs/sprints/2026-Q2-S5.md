# Sprint 2026-Q2-S5

**Status:** Active
**Window:** 2026-06-09 → 2026-06-23
**Goal:** Make Team Leads orchestrate leaf work through the Claude Code
**Workflow** tool instead of spawning persistent Workers — deterministic,
cheap, reliable fan-out — and surface a running Workflow's progress on the
dashboard and Telegram so the org stays visible from your phone. Begin
retiring the persistent Worker entity (the leaf-coordination layer that
carries most of Hive's reliability tax). Plus two carry-forward cleanups:
retire the custom advisor and trim the VPS skill library.

## Committed

- [`013-retire-custom-advisor`](../tickets/013-retire-custom-advisor/) ✱ —
  retire Hive's bespoke `claude -p` advisor MCP tool for Claude Code's
  native `/advisor`. Carry-forward.
- [`014-trim-vps-skill-library`](../tickets/014-trim-vps-skill-library/) —
  filesystem-level removal of unused installed CC skills; the global
  complement to 012's per-role denylist. Follow-up to 012.
- [`015-lead-workflow-leaf-engine`](../tickets/015-lead-workflow-leaf-engine/)
  — give Leads the Workflow tool for leaf fan-out; relax the lead
  `Agent`/`Task` guard. The foundation. ADR-worthy.
- [`016-migrate-leaf-dispatch-to-workflow`](../tickets/016-migrate-leaf-dispatch-to-workflow/) ✱
  — reroute leaf execution from `spawn_worker` to the Workflow engine; drains
  the path that must be empty before the Worker type can be deleted.
- [`017-bridge-workflow-progress`](../tickets/017-bridge-workflow-progress/) ✱
  — bridge a running Workflow's progress (count / phase / partial results /
  completion) into the dashboard + Telegram, reusing Ticket 003's pattern.
- [`018-retire-worker-entity`](../tickets/018-retire-worker-entity/) —
  delete the persistent Worker entity once nothing routes through
  `spawn_worker`. Likely tails into S6.

## Risks

- **Big slice for the window.** The weight is in 015/016/018; 013/014 are
  small. If it overruns, **018 (the deletion) is the natural spill into S6** —
  (c) is the target end-state, reached when 018 lands.
- **016 + 018 collide with `dispatch.py`** — the 1,353-LOC god object parked
  in S4's out-of-scope. Draining `spawn_worker` forces touching it; this
  sprint may pair with, or trigger, a dispatch cleanup.
- **015 reverses a deliberate guard** — leads currently block `Agent`/`Task`
  so they spawn Hive Workers, not CC subagents (`lifecycle_manager.py:69-76`).
  Relaxing it is an ADR-level decision; weigh against role-discipline drift.
- **Nested worktrees** — a Lead runs in a Hive worktree; Workflow agents with
  `isolation: 'worktree'` create worktrees under it. Git allows it, but this
  session hit worktree quirks (`'main' already used by worktree`) — the
  integration must handle them, not assume them away.
- **Visibility regression** — ephemeral Workflow agents don't appear in the
  org tree the way Workers do; 017 must land or the dashboard goes blind to
  leaf work.

## Out of scope

- The named-workflow **interaction-pattern library** (debate, blackboard,
  tournament, research-consolidate …) and the skills that route Leads to them
  — **Track 2**, S6+. S5 ships the engine, not the pattern catalogue.
- **Steering** Workflow agents from the phone (write-back control) — S6+.
  S5's bridge is read-only visibility first.
- Running leaf agents on **non-Claude models** (the cheap-model idea) — needs
  the Phase 4 adapter layer; not this sprint.
- Phase 3 (PWA) — shifted (see roadmap).

## Definition of done

- A Team Lead can decompose a scoped goal and execute it as a **Workflow** run
  (deterministic fan-out), with no `spawn_worker` on the leaf path.
- A running Workflow's progress is visible on the dashboard and pings Telegram
  (count / phase / completion).
- `spawn_worker` is drained from leaf dispatch; the Worker entity is deleted
  (or 018 is explicitly carried to S6 with the path already drained).
- 013: Hive no longer spawns `claude -p`; native `/advisor` enabled.
- 014: the agreed unused skills are removed from the VPS.
- `ruff` + full `pytest -m "not integration"` green; a maestro turn completes
  end-to-end on deployed code.
- INDEX rows for 013–018 reflect final state.
