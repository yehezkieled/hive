# Sprint 2026-Q2-S3

**Window:** 2026-06-01 → 2026-06-15
**Goal:** Begin Phase 2 Restructure — collapse the worst navigability
blockers in `process/` and retire superseded runtime code, with zero
behaviour change and the test suite green between every step.

## Committed

- [`006-worker-rename`](../tickets/006-worker-rename/) — rename the
  `WorkerAgent` class to `Worker` across `src/` and `tests/`.
  Mechanical, ~half a day, near-zero risk. The Phase 2 warmup; a full
  `plan.md` already exists.
- [`004-manager-py-breakup`](../tickets/004-manager-py-breakup/) —
  split `process/manager.py` (2,469 LOC, one 47-method class) into a
  thin core plus four focused modules. Lands as five PRs, tests green
  between each. The sprint centrepiece.
- [`007-remove-headless-runtime`](../tickets/007-remove-headless-runtime/)
  ✱ — retire the headless / non-PTY runtime path now that PTY is the
  production runtime. Commit to PTY-only: remove `ClaudeSession`, the
  `use_pty=False` branches, the headless session-resume logic, and the
  `HIVE_USE_PTY` flag; re-base the unit suite onto a mocked PTY session.

## Risks

- **Ambitious for one window.** 004 (heavy) and 007 (touches the
  runtime *and* the test harness) are both substantive; only 006 is
  trivial. If the window tightens, 007 slips to a follow-up sprint
  first — 004 is the priority.
- **007 rewrites test-harness assumptions.** The unit suite is pinned
  hermetic with `HIVE_USE_PTY=false` (conftest), i.e. it runs *on* the
  headless path. Removing that path means re-basing the suite onto a
  mocked PTY session — design must solve this before any code is
  deleted.
- **007 is a one-way door.** Dropping the headless fallback commits
  Hive to PTY-only. The advisor's one-shot `claude -p` is a separate
  raw subprocess and stays. The decision warrants an ADR (see the
  ticket).
- **004 concurrency hazards.** The non-reentrant `_state_lock` and the
  fire-and-forget task tracking must survive the split unchanged (see
  004 `research.md`).

## Out of scope

- Any behaviour change. All three tickets are pure refactors or
