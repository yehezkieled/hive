# Sprint 2026-Q2-S10

**Status:** Active
**Window:** 2026-06-30 → 2026-07-14
**Goal:** Make the web genuinely usable as **the Delegator's Desk** — the
delegate-and-supervise surface for autonomous loops (roadmap Phase 5,
[ADR 0027](../adr/0027-web-delegators-desk.md)). Today the web is a good monitor
and approver but a poor control panel: ~30 of ~35 capabilities are command-only
and the home page is unusable. S10 rebuilds the home from first principles — a
**Stack home** (needs-you lane as hero + project glance + delegate bar + quota
chip) that opens into a **tabbed Work view** (2–3 maestro conversations, active
tab = default target, clear/history) — on a **trimmed command set**, and cleans
up after. This is the FE-weighted half of the FE+BE cadence; the dogfood +
isolation + harnesses that *fill* the desk are S11 (Phase 6/7).

> **Why now.** Phase 4 shipped the web *surface* (PWA + Web Push, verified on the
> iPad). A first-principles brainstorm chose the **Delegator's Desk** mental model
> (delegate + supervise autonomous loops, not pilot a cockpit) and a home layout
> ("Stack" → tabbed "Work"). The redesign mostly re-surfaces existing capability;
> the one new binding (project ↔ home/loop status) is also what the S11 dogfood
> needs.

## Dependencies

What must land before what. Independent tickets stand alone — grab any time.

```
  050 trim ─(soft)─┬─▶ 051 needs-you lane ──▶ 052 Stack home ◂──▶ 053 Work view
                   └─(soft)────────────────────────────────────┘   (⚠ 053 likely spills → S11)

  054 cleanup   — independent · run LAST (after the redesign lands)
```

Suggested start order (a topo read, not a schedule):

1. **050 first** — trim, so 052/053 wrap only the kept command set.
2. **051 → 052** — the lane, then the home that hosts it.
3. **053** alongside 052 (home ↔ work view are linked; tap a project → its tab).
4. **054 last** — sweeps the scratch once the build is done.

## Risks

- **Two large tickets (052, 053).** A full home + a tabbed conversation view is a
  lot for one window. **053 is the designated spill → S11** if it runs long.
- **051 blast radius.** Folding four approval/decision surfaces into one touches
  the mode/vault/gate/decision paths — keep the full web + approval test suite
  green and re-smoke each interrupt type.
- **On-device re-smokes.** 052/053 change live web behaviour → each needs a
  deployed re-smoke on an **actual iPad** (installed PWA), not just green units.
- **Shared web-file rebasing** — 051/052/053 all touch `src/hive/web`; land order
  matters, later PR rebases.

## Out of scope

- **The dogfood, project isolation, reliability, and the Codex/OpenCode
  harnesses** — all S11 (roadmap Phase 6/7). No real build runs until isolation
  exists.
- **Project create/management UI** — S11 (the dogfood needs it); S10 only
  *displays* existing projects on the home.
- **Mid-run Workflow steering** (ADR 0014) · **new observability widgets** · the
  **architecture-deepening backlog** (Phase 8).
