## Risks

- **041 is large + already spilled once.** Web Push (VAPID + SW + store +
  delivery) is genuinely big and iOS-finicky; it slipped S8→S9 already. If the two
  weeks run short, **041 is the likeliest re-spill → S10** — accept that rather
  than rushing a half-tested push path. Mitigated: 040 (the HTTPS + installed-PWA
  prerequisite) is done, and the `NotificationChannel` seam is clean.
- **On-device re-smokes.** 041/042/043 change live web behaviour and 043's bug is
  invisible to curl/in-Safari → each needs a deployed re-smoke on an **actual
  iPad** (installed PWA, standalone), not just green units.
- **Shared web-file rebasing** (041/042/043 all touch `src/hive/web`).
- **045 blast radius.** `dispatch.py` routes 39 commands; do the **registry first**
  (mechanical, low-risk), then the group extractions, and keep the full command
  test suite green. Watch the CI coverage floor (Ticket 011) when moving logic
  across the unit/integration boundary.
- **044 value is gated on the skill files.** The ticket only ships *awareness*;
  the patterns' worth depends on the developer authoring the global skills.
